# drjekyll.org Homebrew Tap

Welcome to the drjekyll.org Homebrew tap! This repository contains custom Homebrew formulae for our tools.

## How to use this tap

### Adding the tap

To add this tap to your Homebrew installation, run the following command in your terminal:

```bash
brew tap dheid/homebrew-tap
```

### Installing formulae

Once you have added the tap, you can install the available formulae using `brew install`.

To install `adocfmt`, run:

```bash
brew install adocfmt
```
